# Binary Search

A small Java command-line program that searches a sorted array of integers for a target value.

## Run

Compile the program:

```sh
javac src/Main.java
```

Pass the array elements followed by the target value:

```sh
java -cp src Main 1 2 3 4 5 3
```

The program prints the matching index, or `-1` if the target is not found. The example prints:

```text
Result index: 2
```
