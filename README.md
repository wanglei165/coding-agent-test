# 二分查找示例

这是一个 Java 命令行程序，接收一组整数和一个目标值，并输出目标值的索引。

## 环境要求

- JDK（需包含 `javac` 和 `java`）

## 编译与运行

在仓库根目录执行：

```bash
mkdir -p out
javac -d out src/Main.java
java -cp out Main 1 2 3 4 5 4
```

输出示例：

```text
Result index: 3
```

参数依次为按升序排列的数组元素和目标值；索引从 `0` 开始。程序至少需要一个数组元素和一个目标值。未找到目标值时，程序返回 `-1`。

> 注意：当前查找实现未检查搜索区间只剩一个元素时的情况，因此某些实际存在的目标值也可能返回 `-1`。
